Most wellness apps feel like homework. Lantern feels like a porch light.

Generates 1,000+ context-aware Wellness Playbooks. Adapts to weather and severity. Routes high-risk users straight to help. Runner-up at INSPIRE.

The five things that mattered.

/01
Wellness Playbooks
Gemini API + Supabase-backed user profiles generate tailored mental health resources for 1,000+ possible user states on demand.
/02
Weather-aware UI
Open-Meteo data wired into a React theming layer so UI and content adapt in real time to 7+ weather conditions.
/03
Crisis severity tiers
Three-tier severity model escalates high-risk users to immediate support resources before they have to ask twice.
/04
Sub-24-hour build
FastAPI + React + TypeScript end-to-end shipped under one weekend deadline alongside a single teammate.
/05
Designed for the dim hours
Low-contrast palette, low-friction prompts, no streak shame. The app you can open at 2 am.
